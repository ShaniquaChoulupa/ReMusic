# ReMusic (experiment)
Tries to get Google sign-in working in old YouTube Music 3.47.4 on iOS 10.
Idea from TubeReplacer by Preloading (GPLv3). This project is GPLv3 too.
Build: push to GitHub -> Actions -> "Build ReMusic" -> download the artifact (32-bit armv7 .deb).
After installing, open YouTube Music: a pop-up shows the folder with ReMusic-log.txt and ReMusic-classes.txt.
